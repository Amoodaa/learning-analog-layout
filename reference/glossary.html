Glossary

The canonical terms for this workspace. Every lesson uses these words and avoids the aliases. Terms marked introduced haven't yet been shown in practice. They become known once you've used them correctly.

Signal chain

RX front endintroduced
The part of the receiver from the bump to the sampler input: pad, ESD, T-coil, termination and analog front end. Avoid: input stage, RX analog (too vague)
Pad nodeintroduced
The single electrical node (per leg) shared by the pad, ESD clamps, termination and the routing to the CTLE. Its total capacitance sets the input pole. Avoid: input net, RX pin
Termination (RT)introduced
The on-die resistor, matched to Z0, that absorbs the incoming wave so it doesn't reflect. Avoid: load resistor
CTLEintroduced
Continuous-time linear equalizer: a degenerated differential pair that boosts high frequencies to undo channel loss. Avoid: peaking amp, linear EQ
T-coilintroduced
A pair of coupled inductors (often with a bridge capacitor) that hides ESD and input capacitance from the line, extending bandwidth and improving return loss. Avoid: peaking coil, bridged inductor

Bandwidth

Input pole (fp)introduced
1/(2π·Reff·Ctotal) of the pad node, where Reff = Z0 ∥ RT. Avoid: input bandwidth, RC corner
Nyquist frequency (fN)introduced
Half the symbol rate. The frequency where channel loss is specified. Avoid: half-rate frequency
Symbol rate (baud)introduced
Symbols per second. It equals the bit rate for NRZ and half the bit rate for PAM4. Avoid: using "data rate" for this
