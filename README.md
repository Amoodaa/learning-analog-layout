# SerDes RX Front-End Layout: a self-paced course

Interactive lessons and reference sheets on the layout of wireline receiver front ends (pad, ESD, termination, T-coil, CTLE), for layout engineers.

**Read it online:** https://amoodaa.github.io/learning-analog-layout/

- `lessons/`: one short interactive lesson per file
- `reference/`: printable cheat sheet and glossary
- `assets/`: shared stylesheet and widgets (quiz, capacitance-budget tool)
- `MISSION.md`, `RESOURCES.md`, `learning-records/`: the teaching workspace state

Everything is plain static HTML with no build step. All numbers are illustrative and process-generic.
